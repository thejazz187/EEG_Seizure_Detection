# EEG-Based Epileptic Seizure Detection

Machine learning and deep learning framework for automated epileptic seizure detection using EEG signals.

## Models

- Random Forest
- 1D CNN
- Transformer

## Datasets

- Bonn EEG
- CHB-MIT
- Siena
